### Amazon Clone

A pixel-perfect, fully responsive frontend clone of the Amazon homepage. This project was built from scratch using HTML5 and CSS3 to master advanced layout techniques, semantic structural design, and modern web styling practices. 

### ✨ Features

* **Semantic HTML**: Built using modern structural tags (<header>, <footer>) for better accessibility.
* **Navigation Bar**: Complete layout of the Amazon top navigation bar, including the search bar, delivery location, and account options.
* **Responsive Layout**: Designed using CSS Flexbox to ensure a smooth layout across different screen sizes. 
* **Back to Top & Footer**: Functional styling for the multi-tiered Amazon footer and "Back to top" navigation section.
### 🛠️ Tech Stack

* **HTML5**: Structured markup and forms.
* **CSS3**: Custom layout configurations, styling, hover transitions, and responsive design.
